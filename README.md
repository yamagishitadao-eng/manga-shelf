# まんが本棚

いろいろな漫画アプリ（Kindle、ジャンプ+、ピッコマ、紙の本など）で買った漫画を、1か所でまとめて管理するためのWebアプリです。

## できること

- **あいうえお順**に並べて表示（よみがなで並べるので、漢字のタイトルも正しい位置に入ります）
- 行ごとのインデックス（あ・か・さ…）からすぐ移動
- **★1〜5の評価**
- **何巻まで持っているか**を背表紙の棚で表示
  - 黒：持っている巻／黄：抜けている巻／点線：まだ買っていない新刊
- **アプリごとの購入記録**（例：ピッコマ 1〜10巻 → ブックウォーカー 11〜15巻）。背表紙もアプリごとに色分け
- 対応アプリ：ピッコマ、Kindle、ブックウォーカー、DMMブックス、DLsite、アメーバマンガ、ジャンプ+、マガポケ、LINEマンガ、コミックシーモア、ebookjapan、BookLive!、楽天Kobo、紙の本（その他も自由に入力可）
- **1巻の表紙を自動取得**（Googleブックス／国立国会図書館サーチの書影）。保存するのは画像のリンクだけなので軽い。違う表紙なら候補から選び直せる。見つからない作品はタイトル入りの表紙を表示
  - 既存の作品は「バックアップ」画面の「表紙をまとめて取得」で一括取得
- **まとめて登録**：アプリの本棚からタイトルをコピーして「鬼滅の刃 1-23 完結」のように1行1作品で貼り付け、一括登録（登録済みの作品には巻だけ追加）
- **未読リスト**と「何巻の何ページまで読んだ」のしおり、完結・連載中の表示、重複登録の防止
- 「+1巻」ボタンで新刊を買ったらワンタップで記録
- 検索、アプリ別・新刊未購入・抜けあり・完結などの絞り込み
- JSONでバックアップ・読み込み（機種変更や別の端末でも使えます）

データはブラウザ（localStorage）に保存されます。サーバーや外部には送信されません。

## GitHub Pagesで公開する手順

1. GitHubで新しいリポジトリを作る（例：`manga-shelf`）
2. このフォルダの `index.html` と `README.md` をアップロード（「Add file」→「Upload files」）
3. リポジトリの **Settings → Pages** を開く
4. 「Source」を **Deploy from a branch**、Branch を **main / (root)** にして保存
5. 数分後、`https://<あなたのユーザー名>.github.io/manga-shelf/` で使えるようになります

スマホではブラウザの「ホーム画面に追加」をするとアプリのように使えます。

## 注意

- データは端末・ブラウザごとに別々です。別の端末で使うときは「バックアップ」から書き出して読み込んでください。
- ブラウザのデータを消すと記録も消えるので、ときどきバックアップしておくと安心です。
